# supply-chain-agentic-ai
Multi-agent supply-chain platform that combines intelligent fraud detection, predictive route optimization, and Retrieval-Augmented Generation (RAG) to deliver data-driven insights and automated decision support.

# Building, and deployment
Execute btool script to build, do regress unit testing, and deploy this platform of this monorepo (of modular microservices).
Command: chmod +x ./btool.sh; sh ./btool.sh;
